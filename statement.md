# Hospital Management System

## 1. Problem Statement

Managing hospital information manually can be time-consuming and may lead
to difficulties in maintaining and accessing patient, doctor, appointment,
and billing records.

The Hospital Management System provides a simple Java-based solution to
organize these operations and maintain hospital records efficiently.

## 2. Scope of the Project

The project focuses on managing the basic operations of a hospital through
a console-based Java application.

The scope includes:

- Patient record management
- Doctor record management
- Appointment management
- Billing and payment management
- Searching, updating and deleting records
- Doctor availability management
- File-based data storage
- Input validation and error handling

The project is developed for academic purposes to demonstrate the practical
application of Java programming and Object-Oriented Programming concepts.

## 3. Target Users

The system is intended for:

- Hospital administrators
- Reception staff
- Hospital management staff
- Students for academic demonstration

## 4. High-Level Features

### Patient Management
- Add patient
- Search patient
- View all patients
- Update patient details
- Delete patient

### Doctor Management
- Add doctor
- Search doctor
- View all doctors
- Update doctor details
- Delete doctor
- Manage doctor availability

### Appointment Management
- Book appointment
- View appointments
- Cancel appointment
- Complete appointment
- Check patient and doctor availability

### Billing Management
- Generate bills
- View bills
- Search bills
- Calculate total charges
- Make payments
- Check payment status

### Data Management
- Store records using text files
- Load saved records when the application starts
- Handle invalid input and application errors
